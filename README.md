# morelinux-bash-Commads
данный скрипт дополняет коносль дополнителными коммантами

# активация
1.загрузите файл morecommands.sh в любое место
2.выдайте право выполнения chmod +x morecommands.sh
3. запутсите скрипт ./morecommands.sh
4. выберете установить комманды
5. в вашей системе теперь дополнителные комманды
